# Cluster-Forge version migration guides

Step-by-step runbooks for in-place upgrades between cluster-forge releases.

| From | To | Guide |
|---|---|---|
| v2.1.x | v2.2.x | [v2.1.x-to-v2.2-migration.md](../v2.1.x-to-v2.2-migration.md) |
| v2.2.x | v2.4.x | [v2.2.x-to-v2.4-migration.md](v2.2.x-to-v2.4-migration.md) |

There is no v2.3 release — clusters on v2.2.x upgrade directly to v2.4.x.

Older guides remain at their original paths so external links (for example from
[AMD Enterprise AI Suite docs](https://enterprise-ai.docs.amd.com/en/latest/platform-infrastructure/on-premises-installation.html))
stay valid.
