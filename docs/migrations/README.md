# Cluster-Forge version migration guides

Step-by-step runbooks for in-place upgrades between cluster-forge releases.

| From | To | Guide |
|---|---|---|
| v1.8.x | v2.0.x | [v1.8-to-v2.0-migration.md](v1.8-to-v2.0-migration.md) |
| v2.1.x | v2.2.x | [v2.1.x-to-v2.2-migration.md](v2.1.x-to-v2.2-migration.md) |
| v2.2.x | v2.4.x | [v2.2.x-to-v2.4-migration.md](v2.2.x-to-v2.4-migration.md) |

There is no v2.3 release — clusters on v2.2.x upgrade directly to v2.4.x.

Canonical paths live under `docs/migrations/`. Short redirect stubs remain at
legacy top-level paths (`docs/v2.1.x-to-v2.2-migration.md`,
`docs/upgrade_v2.md`) for bookmarks and external links pending updates.

Referenced from
[AMD Enterprise AI on-premises installation](https://enterprise-ai.docs.amd.com/en/latest/platform-infrastructure/on-premises-installation.html).
